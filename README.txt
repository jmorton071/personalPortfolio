Project Title: Joe Morton Personal Portfolio
Brief Description: This is a portfolio of my work, mainly my Computer Science work, with some information about me and my projects, my contact
info, and my resume. 
Technologies Used
HTML: HTML makes the skeleton of my portfolio, the sections, words, title, etc.
CSS: CSS does the heavy lifting of making the portfolio look good, otherwise it would be black and white and nowhere near as visually appealing.
JavaScript: JavaScript is used to allow for dynamic sizing of the window and elements on the site.
Template: I used the Hyperspace template from HTML5, found here: https://html5up.net/ 
Deployed Website Link: https://joe-morton-portfolio.onrender.com/index.html 
How to Run the Website Locally: Using LiveServer I was able to run the website locally from any HTML files, 
just by clicking the globe icon in the upper right corner.
Challenges: I struggled to get the mailto function to work for the email, it would just do nothing when I clicked it. I also struggled to get
small icons for each of the projects I listed to appear on the main page next to their titles and descriptions. Because I was struggling and I did
not have a logo for each project, I removed the side photos entirely. 
Future Improvements:
I would like to get the mailto function to work on the contact section, and include a small "send message" box like many websites have and was 
originally in the template. I would also like to make some more pages that go into detail about club activities I have led or participated in,
